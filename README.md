# 油字幕 · V-Translate

此軟件為免費 【本地即時 AI 翻譯器】，<br />
可以實時翻譯 Vtuber 字幕<br />
(或Chrome /Edge 內**任何聲音**-> 中/英 字幕翻譯)<br />
<br />
vibecoding using Codex<br />

This software is a free, local, real-time AI translator.<br />
It can provide instant translation for VTuber subtitles,<br />
as well as translate **ANY** audio into subtitles (within Chrome or Edge).<br />

## v1.6.0 Windows 更新

- 分享直播分頁前可選唱回、雜談或回放模式。唱回採用 256 kbps Opus，反覆卡頓時會自動增加緩衝。回放會參考相鄰原文並等待定稿字幕。
- 高效能起始緩衝預設為 5 秒，均衡為 10 秒，入門為 14 秒。播放器滑桿最低可手動調到 3 秒。
- 已儲存的設定會保留。可在效能設定按「套用建議緩衝」套用新預設。

[下載 Windows v1.6.0](https://cookieproduction853.github.io/V-Translate/downloads/V-Translate-v1.6.0-Windows-x64.zip) · [官網](https://cookieproduction853.github.io/V-Translate/)

## v1.6.0 Apple Silicon 更新

適用 Apple M 系列及 macOS 13.5 或更新。Apple Metal 可加速 Whisper 聽寫和文字翻譯。效能選單提供高效能、均衡、入門，高效能的起始緩衝為 5 秒，播放器滑桿最低可手動調到 3 秒。分享前可選唱回、雜談或回放模式。

套件以 ad-hoc 簽署，尚未經 Apple 公證。請參閱 ZIP 內的安裝說明。
