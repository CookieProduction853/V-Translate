正在讀取詞彙包…

檔案須為 UTF-8（可含 BOM），上限 64 KiB。CSV／TSV 使用 source、target 兩欄，可加 reading 欄；TXT 每行一個原文用語。可先用試算表另存 CSV／TSV；不支援 XLSX、TBX、TMX 或任意模型權重（.bin／.gguf／.safetensors）。詞彙包提供提示，效果取決於聲音及模型。擷取期間請先結束擷取，再切換用語。

本機

Mac 請使用最新版 Chrome／Edge 分享直播分頁及分頁音訊；Safari／Firefox 不支援本播放器需要的分頁音訊。若擷取被拒絕，請到「系統設定 → 隱私權與安全性 → 螢幕與系統音訊錄製」允許此瀏覽器，必要時重新開啟瀏覽器。

尋找翻譯模型（Ollama） ↗

Ollama 模型庫用來找模型；套件／Modelfile 並非直接 GGUF 下載。請取得支援所需語言、與 llama.cpp 相容的 instruct／chat GGUF。CPU 可先試小型 Q4_K_M 量化；相容性與翻譯品質依模型而異。

使用說明

安心沿用你的觀看方式

請在瀏覽器登入並開啟直播，再選擇分享分頁。會限內容依平台與你的帳號權限播放；受保護而無法擷取的畫面無法在此播放。

建議使用最新版 Chrome／Edge。Firefox 目前不支援此播放器需要的分頁音訊擷取。初次下載模型需要網路，字幕處理在本機進行。關閉播放器後，背景程式會在 3 分鐘內退出；也可按播放器下方的「關閉背景聽寫程式(whisper)」立即關閉。

AMD Radeon（包括 RX 9070）及支援 Vulkan 的 NVIDIA GeForce 可使用顯卡聽寫和翻譯；請更新對應品牌的顯卡驅動，不需另外安裝 CUDA Toolkit。若顯卡模式無法啟動，請選 CPU 後重新準備 AI。

若 AI 引擎提示缺少 Windows DLL，可安裝 Microsoft VC++ x64 執行元件，再重新開啟程式。

請保持來源分頁播放。瀏覽器會嘗試停播來源聲音，避免雙重聲音。若手動靜音來源後字幕停止，請取消靜音並檢查分頁音訊分享。
