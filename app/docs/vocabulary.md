# VTuber 詞彙包

詞彙包讓 油字幕（V-Translate） 的聽寫及翻譯參考 VTuber 人名、粉絲名稱、口頭禪和指定譯名。它可使用 UTF-8 JSON、CSV、TSV 或 TXT 檔案分享，不需要安裝 Python，也不需要在自己的電腦重新訓練模型。

## 匯入和使用

1. 下載相容的 `.json`、`.csv`、`.tsv` 或 `.txt` 詞彙檔，或先使用介面提供的範例。儲存庫另附有 [示例檔案](../examples/vtuber-vocabulary.json)。
2. 在播放器的詞彙包區域選擇檔案並匯入。匯入完成後，從清單**選取要啟用的詞彙包**；單純匯入不會自動啟用。
3. 再開始擷取直播。若要換台或更換詞彙包，先結束擷取，再選其他詞彙包；選擇不使用詞彙包即可停用。
4. 不再需要的詞彙包可從介面移除。移除詞彙包不會刪除語音或翻譯模型。

最多可保存 64 個詞彙包。詞彙包及目前選擇會保存在本機資料目錄，重新啟動後可繼續使用。請按主播及語言整理，避免一個包混入大量不相關的名字。內附「星乃測試台」是虛構示例，沒有代表任何真實 VTuber 的訓練成果。

## JSON 完整格式

```json
{
  "format_version": 1,
  "name": "星乃測試台・日文詞彙示例",
  "language": "ja",
  "terms": [
    {
      "source": "星乃ルミ",
      "reading": "ほしのるみ",
      "target": "星乃露米"
    },
    {
      "source": "おつルミ",
      "reading": "おつるみ",
      "target": "露米辛苦了"
    }
  ]
}
```

| 欄位 | 意義與限制 |
| --- | --- |
| `format_version` | 必填，目前為數字 `1`。 |
| `name` | 必填，詞彙包名稱，最多 80 個字元。 |
| `language` | 可省略；提供時為 `ja`、`en`、`zh`、`ko` 或 `auto`。請在播放器另行選擇正確的直播語言。 |
| `terms` | 必填，1–128 個詞條。 |
| `source` | 必填，原文詞彙，最多 80 個字元。 |
| `reading` | 可省略，讀音提示，最多 80 個字元。 |
| `target` | 可省略，希望採用的翻譯／譯名，最多 120 個字元。 |

檔案大小上限為 64 KiB，格式只接受上述欄位。名稱及詞條不可為空白或包含控制字元；同一包內的 `source` 不可重複。匯入不會執行檔案中的程式碼，也不接受壓縮包或程式檔。`target` 應配合你所選的翻譯語言；例如繁中譯名不適合直接拿去做英文翻譯。

## 怎樣影響字幕

原文及讀音會成為語音引擎的有限長度提示，協助辨識模型認出名稱與慣用詞。翻譯時，程式會把相關詞條提供給文字模型作為譯名參考。為了保留模型的處理空間，提示有長度限制，較大的詞彙包不保證每個詞條都會同時進入提示。

這個功能沒有更改模型權重，也沒有在背景訓練模型；原始音訊仍是辨識依據。提示可能有幫助，也可能讓不相關的詞彙干擾辨識。它不保證精準度提升、不保證每次都使用指定譯名，也無法補回聽不清楚的聲音。建議只保留常用且容易認錯的詞，並用同一段聲音比較效果。

## 別人已經訓練好的模型檔案

如果你下載的是 `.bin`、`.gguf`、`.safetensors`、LoRA 或 adapter，它可能是模型權重或訓練增量，與這個 JSON 詞彙包格式不同。**目前詞彙包匯入器不支援載入這些模型檔案。** 副檔名也不足以判斷能否相容：還要看模型架構、匯出格式、所需基底模型和推論引擎。

請向分享者索取模型名稱、檔案格式及使用說明，以確認日後是否能加入對應載入功能。現有的模型完整性檢查會驗證下載內容，直接改名覆蓋 `models` 中的官方模型可能導致校驗失敗。

## 常見詞彙交換格式

| 格式 | 內容 | 範例 |
| --- | --- | --- |
| CSV | 逗號分隔的原文、譯文兩欄；可選第三欄讀音 | [CSV 範例](../examples/vtuber-vocabulary.csv) |
| TSV | Tab 分隔，欄位同 CSV | [TSV 範例](../examples/vtuber-vocabulary.tsv) |
| TXT | 每行一個原文詞語，作為聽寫提示 | 人名或口頭禪各自一行 |

支援 UTF-8（含 BOM）、CRLF，CSV 的引號及引號內逗號。可省略標題列；使用標題時，前兩欄可為 `source,target` 或 `原文,譯文`。請由 Excel／Google Sheets 匯出 UTF-8 CSV 或 TSV；不直接讀取 XLS／XLSX、TBX、TMX 或多語言四欄詞彙庫。這是常見兩欄詞彙的交換支援，不宣稱所有翻譯工具的格式都能直接載入。單個詞條不接受換行等控制字元。

選取詞彙包後可匯出 CSV／TSV，以便其他工具使用。這些匯出只保留原文與譯文兩欄，讀音、名稱、語言等資訊會省略；要完整分享請保留原始 JSON。TXT 只有原文，所以不包含指定譯名。檔案大小及詞條數限制與 JSON 相同。
