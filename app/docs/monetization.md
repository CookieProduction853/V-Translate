# 廣告與贊助合作

v0.4.2 在詞彙包下方預留約 250 px 高的靜態「廣告／贊助」卡片，與播放器操作按鈕保持距離。目前顯示的是合作邀請，沒有接入廣告平台、廣告腳本或發布者 ID，也沒有曝光／點擊回報或自動廣告收入。

## 先從直接贊助開始

有意合作可按卡片的「洽談贊助合作 ↗」，或來信 [vtranslate853@gmail.com](mailto:vtranslate853@gmail.com)。這會開啟使用者自己的郵件程式；一般聯絡及用戶要求亦歡迎使用同一地址。

實際刊登前，可先與贊助者約定靜態圖片或文字、連結、刊登期間、費用及付款方式，再更新卡片內容並清楚標示贊助。現有版位沒有提供自動計費或成效報表，因此合作條件應以雙方另行確認的協議為準。

## 如要接入廣告平台

Google Ads、Microsoft Advertising 等廣告主帳戶主要用於購買廣告；建立帳戶不代表這個應用程式已能作為發布者收取廣告收入。接入廣告網絡仍需找到支援此產品形態的發布者方案、完成平台審核，並另外實作相容的整合。

Google 官方的 [Google Mobile Ads Unity 外掛說明](https://github.com/googleads/googleads-mobile-unity/blob/main/README.md) 將其用途描述為在 **Android 與 iOS 應用程式**顯示行動廣告。這說明該 SDK 的平台範圍，不能據此判定 Windows 桌面應用程式是否符合其他 Google 發布者方案資格，也不能直接把這個行動 SDK 當成目前播放器的整合方式。

若日後另外經營公開網站，可再評估 AdSense 等網站發布者方案，向提供者確認網站是否符合條件；獲接受及完成整合前，不應把預留卡片描述為已啟用的廣告收益功能。AdSense、AdMob 或 Microsoft 發布者方案對本產品的適用資格，本文沒有確認；應以提供者對實際產品的最新答覆為準。

後續可查閱 [AdSense 廣告刊登位置政策](https://support.google.com/adsense/answer/1346295)、[AdMob 開發者入口](https://developers.google.com/admob) 及 [Microsoft pubCenter 入口](https://about.ads.microsoft.com/en/solutions/tools/pubcenter)。本次讀取這些頁面時收到 HTTP 403，未能核對最新政策、香港地區資格或 Windows／localhost 支援情況。
