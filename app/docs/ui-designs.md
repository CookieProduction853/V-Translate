# 油字幕 / V-Translate 介面

頁首提供繁體中文（zh-Hant）／English（en）語言選擇，以及兩款主題。選擇會保存在本機；切換不會中斷字幕擷取或更換模型。

| Daylight（light） | 暖白靛藍，適合明亮環境 | [完整預覽](ui-light.png) |

「關閉背景聽寫程式(whisper)」是「結束擷取」下方的大按鈕。首次使用為高配置：Small、6 個執行緒、5 秒音訊片段及 20 秒起始緩衝；已有設定會沿用，亦可改選中或低配置。

右側設定另有「翻譯模型」清單、「開啟自訂模型資料夾」及「重新掃描」按鈕。預設使用內建 Qwen，也可選取自行放入的相容 GGUF；先結束擷取，選取模型後自動儲存，再準備 AI。「尋找翻譯模型（Ollama） ↗」會在新分頁開啟翻譯模型搜尋頁，不會連接 Ollama API。操作及限制見[自訂模型說明](custom-models.md)。

v0.4.1 已加入使用者提供的原始 PNG，並轉成多尺寸 ICO，供播放器、執行檔、應用程式視窗及工作列使用。原始圖片保留不變；Windows 桌面上的實際顯示仍待真機驗證。若仍顯示舊圖示，先關閉舊背景程式再開啟新版；已釘選的工作列圖示可取消釘選後重新釘選，以更新 Windows 快取。

預覽取自 v0.4.1 實際介面，使用測試引擎狀態，並非真實直播辨識結果。
